# Musicality_Data_Expedition_2026
This repo includes instructions on how to run this class module with suggestions for future iterations

* 'Musicality_completed_code_example.Rmd' includes the R markdown code that they will be copying during the live coding portion of the class. For future users, keep all regular text, but delete all code from the chunks, and share the code-empty Rmarkdown file with the students to work in. Keep the completed one for your reference while teaching and/or troubleshooting. Alternatively, you could also create an Rshiny app for this module, especially if this module is ever ran during a shorter class period. 
* 'Musicality_Homework_Question.docx' includes the questions that the groups will be answering together for each of the 3 models they will be runing with their code.
* 'Musicality_2026_code_instructions' is the coding lesson plan given to the students. This is for the instructor to refer back to if they need help describing a certain package, function, or plot while live coding.
  * For additional inspiration watch our live coding highlights: https://drive.google.com/file/d/1BjH07inmGfZfYpdXIZKZCBW45NiTb6Yz/view?usp=sharing
* 'Musicality_presentation_fall2026' is the slide show we used to introduce musicality at the beginning of class.
  * How to explain rhythm: https://drive.google.com/file/d/1pEkxBwB0brcKUOmNQjFGOI2jEi8HHz-3/view?usp=drive_link
  * How to explain pitch: https://drive.google.com/file/d/1eYkxMbEgGXO5CH2q7Q6WIsjoIwUHO-d0/view?usp=drive_link
  * Distinguishing the characterists between rhythm and pitch: https://drive.google.com/file/d/1_f_P-BeOG5lVt-v4QE84dLl_1XBFVKqE/view?usp=sharing
* 'Musicality_data_fall2026' is the data we collected during class.
* 'Musicality_class_data_plots' are the plots and p-values we got after analyzing the whole-class data together.
* 'how_to_run_this_modules' walks the next instructors through how we decided to run this module
* 'suggestions_for_the_future' provides examples of how this module could change for future iterations to provide new and exciting learning experiences.
