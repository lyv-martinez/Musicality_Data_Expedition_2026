# Suggestions for future instructors who want to run another iteration of this module
* Add  an exploratory section with the glm. Have the students stick in what ever variables they want, to see what happens.This will get them thinking about what they would want as an independent and dependent variable and what types of questions glm's are useful for.
* Add another binary variable column that marks whether a student can speak 2 of more languages and see if that is correlated with a low rhythm/pitch ratio.
* Have the students get in groups of 4. This will be a better subset sample size.
* Do not give the students a choice between downloaded R and online Rstudio. Have them all download R. The online version caused some issues for the students using it. 
* For the repetitive functions in ggplot code (ex: calling data, x, and y, labels, theme) prewrite a skeleton version for the students and then teach them to copy and paste for the other models to make the coding portion of class run faster.
* Maybe choose some sort of other challenge for the students to do instead of making plots for their groups data after analyzing the whole class data. The transition felt a bit off. Perhaps at the beginning have the students learn some dplyr functions for data manipulation prior to the data visualization portion.
